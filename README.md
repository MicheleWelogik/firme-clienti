# firme-clienti

Immagini delle firme email dei clienti di Logik S.n.c. (loghi e iconcine), pubblicate con GitHub Pages
così le firme le caricano da qui invece di allegarle a ogni mail. Una cartella per cliente.

| Cliente | Cartella | Indirizzo da usare come `baseurl` in FirmeLogik |
|---|---|---|
| Recuperi Service S.r.l. | `recuperi-service/` | https://michelewelogik.github.io/firme-clienti/recuperi-service/ |

File di Recuperi Service: `logo-recuperi-firma.png` (firma chiara) e `logo-recuperi-firma-scuro.png` (firma scura, su fondo #1E1E1E).

Regole:
- Qui vanno solo immagini pubbliche (loghi, icone). Niente dati personali, niente documenti.
- Per aggiornare un logo si sostituisce il file con lo stesso nome: le firme già installate si aggiornano da sole.
